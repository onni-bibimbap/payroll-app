# Glossary — _shared
Sources: PRD, README.md, `backend/app/core/*` · Last verified: 2026-09-03

| term | means | never confuse with |
|---|---|---|
| EPF / KWSP | Employees Provident Fund — retirement savings, employee 11% + employer 12–13% | SOCSO |
| SOCSO / PERKESO | Social Security Organisation — injury/invalidity schemes, banded table | EIS |
| EIS / SIP | Employment Insurance System — 0.2% each side, no foreigners/≥60 | SOCSO (same bands, different scheme) |
| PCB / MTD | Potongan Cukai Bulanan — monthly income-tax deduction | annual tax filing |
| statutory wage | wage base contributions are charged on | total remuneration paid |
| sen | 1/100 MYR — all DB money is integer sen | float ringgit |
| payroll run | one month's computed pay for all included employees | payslip (per employee) |
| movements | month's hires + leavers | status history |
| blocker flag | HR issue that blocks activation/payroll | warning flag |
| activation | approval to `active` with employee_no | status edit |
| NRIC | Malaysian identity card no. — 12 digits, YYMMDD prefix, stored as TEXT | passport/UNHCR id |
| outlet | physical F&B location (KL/Setapak) | department |
| Khusus Makanan / food-handler cert | KKM-mandated food-handling certificate | typhoid proof (separate doc) |
